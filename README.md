# ALA 1 - Ejercicio 2: Calculadora básica

## Descripción
Calculadora simple que resuelve las 4 operaciones básicas (suma, resta, multiplicación y división) 
unicamente entre dos operandos ingresados por la persona usuaria.
Se presupone que el usuario no va a ingresar datos erroneos.

## Cómo ejecutar
1. Instalar dependencias: `npm install`
2. Ejecutar: `node ejercicio2.js`
3. Ingresar el operador deseado (+, -, *, /) y los dos números cuando se solicite.
